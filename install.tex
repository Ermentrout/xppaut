\title{Installing \XPP}
\date{}
\maketitle
\XPP is installed either by compiling the source code or by downloading a
binary for your computer.  The program, the documentation and the binaries
are linked from my home page,
\begin{verbatim}
https://sites.pitt.edu/~phase/
\end{verbatim}
If you are not used to compiling programs, it is easiest to ask your system
administrator or to use a binary.

\section{Compiling the source (Linux and other Unix systems)}
You need a C compiler and the X11 development files.  On Debian and Ubuntu:
\begin{verbatim}
sudo apt install build-essential libx11-dev
\end{verbatim}
Unpack the source code, change to its directory and type
\begin{verbatim}
make
\end{verbatim}
Lots of things will scroll by, including warnings that you can safely ignore.  If
there are no errors you will have a file called {\tt xppaut}; try it:
\begin{verbatim}
./xppaut ode/lecar.ode
\end{verbatim}
If the compilation stops quickly, the compiler probably cannot find the X11 libraries or
header files: edit the {\tt Makefile} and add the right paths, {\tt -I<include path>} to
{\tt CFLAGS} and {\tt -L<library path>} to {\tt LFLAGS}.  (The Makefile already links with
{\tt -fcommon}, which current compilers need.)

You can copy {\tt xppaut} to a directory in your path, or, if you have root
privileges, type {\tt make install} to install the program, the manual, the man page and the
examples in the default directories; {\tt make uninstall} removes them.  \XPP needs no environment
information, but you can change many things with the {\tt .xpprc} file, which is described in
the manual.

\subsection{If the zoom rectangle is not drawn}
On some systems the zooming and cursor movement do not work properly.  Then start \XPP with
\begin{verbatim}
xppaut -xorfix file.ode
\end{verbatim}

\subsection{A launcher on Linux}
You can run \XPP from the command line, {\tt xppaut file.ode}.  In Ubuntu it is also easy to
make it drag and drop: right click on the Desktop and choose Add Launcher, and put the full path of
{\tt xppaut} in the command.  Then you can drag ODE files onto the launcher.

\section{macOS}
Current versions of macOS do not include an X11 server.  Install XQuartz (from
{\tt xquartz.org}) and the command line developer tools, and compile as above; the Makefile already
looks for the X11 headers in {\tt /opt/X11/include}.  Start XQuartz first, and then run
{\tt ./xppaut ode/lecar.ode} from a Terminal window.

\section{Windows}
Binaries for Windows, and instructions, are linked from my home page.

\section{Building the documentation}
The PDF files are made with LaTeX; type {\tt make docs}.  The manual needs the figure {\tt DutchBoy.png}.
